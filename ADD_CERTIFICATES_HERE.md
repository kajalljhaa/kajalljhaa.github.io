# Certificate PDFs

Place your certificate PDF files here. File names must match exactly what is set in `data/certifications.json`.

Default expected files:
- `microsoft-pbi-associate.pdf`
- `azure-dp900.pdf`
- `google-data-analytics.pdf`
- `datacamp-ml-scientist.pdf`
- `aws-cloud-practitioner.pdf`

To add more certificates, add entries to `data/certifications.json`.
