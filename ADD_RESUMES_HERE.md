# Resume PDFs

Place your resume PDF files here. File names must match exactly what is set in `data/resume.json`.

Default expected files:
- `Alex_Morgan_Data_Analyst.pdf`
- `Alex_Morgan_Business_Analyst.pdf`
- `Alex_Morgan_PowerBI_Developer.pdf`
- `Alex_Morgan_ML_Engineer.pdf`

To add more resume variants, add entries to `data/resume.json`.
